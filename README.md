# Лендинг вебинара «Готов ли ваш ребёнок к школе?»

Одностраничный лендинг под вебинар для родителей детей 6 лет. Цель страницы —
собрать регистрации на эфир и продать годовую программу подготовки к школе,
попутно показав саму школу.

Чистые HTML + CSS + vanilla JS: ни сборщика, ни npm, ни фреймворков. Точка входа —
`index.html`. Папка автономная: свои `assets/`, `css/`, `js/`, никаких ссылок
на соседние проекты.

## Как запустить локально

Открывать файл напрямую нельзя — шрифты и `fetch` упрутся в CORS. Поднимаем сервер:

```sh
python3 -m http.server 8765
# http://localhost:8765/index.html
```

## Состояние проекта

Лендинг рабочий: кнопки живые, вёрстка не разъезжается, таймер тикает.
Три вещи ждут вводных от клиента — дата эфира, ID CRM-формы Битрикс24 и фото
второго спикера. Список с точными местами правки — в [CLAUDE.md](CLAUDE.md).
